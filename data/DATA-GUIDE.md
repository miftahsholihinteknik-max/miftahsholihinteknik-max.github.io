# DATA GUIDE

Edit `profile.json` untuk profil, skill, links, research, contact. Edit `publications.json` untuk publikasi, `courses.json` untuk mata kuliah, dan `resources.json` untuk bahan ajar.

Contoh file resource:
```json
{"label":"Modul PDF","type":"PDF","url":"materials/machine-learning/pertemuan-01/modul.pdf"}
```
